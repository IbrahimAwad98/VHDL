# VHDL

VHDL projects that show how to design digital circuits for FPGA and ASIC.

## Files

- `Del1.vhd` - part 1 of a larger project. Entity and architecture, port mapping, and signal handling.
- `Gray.vhd` - a Gray code converter. Converts between binary and Gray code.
- `del2.vhd` - part 2 of the project. Extra logic, helpers, and test benches.

**About Gray code:** in Gray code, two values next to each other differ in only one bit. This reduces errors when signals change.

## Technology

- Language: VHDL
- Used for FPGA design, ASIC design, and digital logic

## Recommended tools

- Simulation: ModelSim, GHDL, Vivado Simulator, Quartus Prime
- Synthesis: Xilinx Vivado, Intel Quartus, Lattice Diamond
- Editor: VS Code with a VHDL extension
